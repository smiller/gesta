# A link to a line

Asked 2026-11-05, on the first look at the Punica's Book 1: a link in a book's Argument selected the line's words, which raised the format bar and marked the sentence's English, though that English translates several lines. "It would be neater if it just highlighted line 672."

REVIEW CYCLES: 0

## Decisions

- An address can name a line: `#bookshelf/…/Book%201?line=672`. It is a new payload beside `?h=`, which still selects words; references and contents links keep `?h=`.
- It lands as ⌃⌘G does, on the first line of that number in the page's order, with no selection and no format bar, and says nothing unless the page lacks the line. On a work by book, chapter, and paragraph it names a paragraph.
- No bar stands open to end the mark, so the next mouse press or key press does. Clicking the same link again marks the line again rather than saying "already here".
- In a `::: dual-language` block the mark is the row's band across both columns, for the links and ⌃⌘G alike (asked: "it should highlight both the text and translation of line 672"). A Latin-only mark was built first, on a misreading of his comment, and taken out the same day.
- A rename or re-file moves an address with its line (`entryHash` writes it back).

## Measured

- Six readings of a new Helium section, "a link to a line", plus a seventh: the band on the row in a dual-language block.
- The Punica's Argument links use it; `?h=` links elsewhere are unchanged.
